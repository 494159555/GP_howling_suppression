# 第2章 Word公式格式版本

## 2.1.2 声反馈的数学建模

**公式（2.1）**
扬声器输出信号$x(t)$是麦克风信号$y(t)$经过延时和增益放大后的结果：

```
x(t) = y(t - Δt) × G     (2.1)
```

**公式（2.2）**
考虑到实际扬声器系统可能产生的非线性失真（如信号削波、谐波失真等），反馈信号$d(t)$的数学表达式为：

```
d(t) = NL[x(t)] * h(t)     (2.2)
```

其中NL[·]表示非线性失真函数，$h(t)$表示声学路径脉冲响应，$*$表示线性卷积运算。

**公式（2.3）**
将式（2.1）代入式（2.2）可得：

```
d(t) = NL[y(t - Δt) × G] * h(t)     (2.3)
```

**公式（2.4）**
麦克风输出的混合信号$y(t)$由目标声源信号$s(t)$和反馈信号$d(t)$两部分叠加而成：

```
y(t) = s(t) + d(t) = s(t) + NL[y(t - Δt) × G] * h(t)     (2.4)
```

## 2.1.3 啸叫产生的条件

**公式（2.5）**
对式（2.4）两端实施傅里叶变换，并忽略非线性失真（即NL[x] ≈ x），可得系统的开环传递函数：

```
H_open(f) = G · H(f) · e^(-j2πfΔt)     (2.5)
```

**公式（2.6）**
振幅条件（环路增益不小于1）：

```
|H_open(f)| = G · |H(f)| ≥ 1     (2.6)
```

**公式（2.7）**
相位条件（形成正反馈）：

```
∠H_open(f) = ∠H(f) - 2πfΔt = 2nπ,  n = 0, ±1, ±2, …     (2.7)
```

## 2.2.2 跳跃连接的作用

**公式（2.8）**
从数学角度看，假设编码器第$i$层的输出为$E_i$，解码器第$i$层的上采样输出为$D_i^(up)$，则解码器第$i$层的实际输入为：

```
D_i^(in) = Concat(D_i^(up), E_i)     (2.8)
```

其中Concat表示通道维度的拼接操作。

## 2.3.1 注意力机制的基本思想

**公式（2.9）**
给定查询向量**q**、键向量集合{**k**_1, **k**_2, …, **k**_N}和对应的值向量集合{**v**_1, **v**_2, …, **v**_N}，注意力机制的输出是所有值向量的加权和：

```
Attention(**q**, **K**, **V**) = Σ_(i=1)^N α_i **v**_i     (2.9)
```

**公式（2.10）**
其中注意力权重$α_i$通过查询向量与键向量的相似度计算并经归一化得到：

```
α_i = [exp(score(**q**, **k**_i))] / [Σ_(j=1)^N exp(score(**q**, **k**_j))]     (2.10)
```

## 2.3.2 注意力门在U-Net中的应用

**公式（2.11）**
注意力门首先分别对**x**和**g**进行1 × 1卷积变换，将它们映射到相同的中间维度空间：

```
**q**_att = ψ^T[σ₁(W_x^T **x** + W_g^T **g** + b_g)] + b_ψ     (2.11)
```

其中W_x和W_g分别是作用于**x**和**g**的1 × 1卷积权重，ψ是输出维度为1的1 × 1卷积，σ₁为ReLU激活函数。

**公式（2.12）**
经过Sigmoid激活函数σ₂后，得到一个空间注意力系数图：

```
α = σ₂(**q**_att)     (2.12)
```

**公式（2.13）**
注意力门的最终输出为编码器特征图与注意力系数的逐元素乘积：

```
**x**̂ = **x** · α     (2.13)
```

## 2.4.1 残差学习的原理与优势

**公式（2.14）**
残差学习的核心思想是不直接学习目标映射$H$(**x**)，而是学习残差映射$F$(**x**) = $H$(**x**) - **x**。原始映射被重构为：

```
$H$(**x**) = $F$(**x**) + **x**     (2.14)
```

其中**x**是通过跳跃连接直接传递的恒等映射，$F$(**x**)是网络需要学习的残差函数。

## 2.4.2 空洞卷积扩大感受野的原理

**公式（2.15）**
对于空洞率为$r$的空洞卷积，卷积核相邻元素之间插入r-1个零值，使得原本大小为k × k的卷积核的有效感受野扩大为：

```
k_eff = k + (k-1)(r-1) = k · r - r + 1     (2.15)
```

## 2.5.1 STFT的原理与实现

**公式（2.16）**
设离散时间信号为$x(n)$，窗函数为ω(n)，则STFT的数学定义为：

```
X(m, k) = Σ_(n=0)^(N-1) x(n + mH) · ω(n) · e^(-j(2π/N)kn)     (2.16)
```

其中m表示帧索引，k表示频率索引（k = 0, 1, …, N-1），N为FFT长度（即频率分析点数），H为帧移。

**公式（2.17）**
幅度计算：

```
|X(m, k)| = √[Re²(X(m, k)) + Im²(X(m, k))]     (2.17)
```

**公式（2.18）**
相位计算：

```
φ(m, k) = arctan[Im(X(m, k)) / Re(X(m, k))]     (2.18)
```

## 2.5.2 时频分析与频谱掩膜估计

**公式（2.19）**
设带啸叫信号的STFT为$Y(m,k)$，干净目标信号的STFT为$S(m,k)$，则理想比值掩膜定义为：

```
M_ideal(m,k) = |S(m,k)| / |Y(m,k)|     (2.19)
```

**公式（2.20）**
增强后的信号通过对带啸叫频谱施加掩膜得到：

```
Ŝ(m,k) = M(m,k) · Y(m,k)     (2.20)
```

**公式（2.21）**
输入特征首先进行对数变换和归一化：

```
Ŷ(m,k) = [log₁₀(|Y(m,k)| + ε)] / [max_(m,k)[log₁₀(|Y(m,k)| + ε)]]     (2.21)
```

其中ε是一个小常数（如10^(-8)），用于避免对零值取对数。

## 使用说明

1. **在Word中插入公式**：
   - 将光标定位到需要插入公式的位置
   - 按快捷键 `Alt + =` 打开公式编辑器
   - 复制上述公式中的数学表达式粘贴到公式编辑器中

2. **公式符号说明**：
   - 使用Unicode数学符号（如 Σ, π, Δ, α, β, θ）
   - 上标使用 `^` 符号（如 e^(-j2πfΔt)）
   - 下标使用 `_` 符号（如 α_i）
   - 分数使用 `/` 或 `÷` 符号
   - 求和符号：Σ
   - 积分符号：∫
   - 平方根：√

3. **公式编号**：
   - 公式编号已按照本科毕设规范格式标注
   - 采用 `(章节.序号)` 格式，如 `(2.1)`, `(2.2)`

4. **注意事项**：
   - 粗体向量用 `**` 包裹（如 **x**, **q**）
   - 矩阵和向量保持加粗格式
   - 数学函数（如 sin, cos, log, exp）保持正体
   - 角度符号使用 ∠
   - 自然常数使用 e

5. **直接粘贴**：
   - 上述公式可以直接复制粘贴到Word中
   - Word会自动识别并转换为可编辑的公式格式
   - 部分复杂公式可能需要微调格式

6. **推荐操作流程**：
   - 复制单个公式
   - 在Word中按 `Alt + =`
   - 粘贴公式
   - 检查并调整格式
   - 确认公式编号正确
