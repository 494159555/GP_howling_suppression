## ⚡ 快速操作流程

### 步骤1：打开两个窗口
- 左侧：`02_chapter2_word_formulas.md`（公式源文件）
- 右侧：Word中的论文文档

### 步骤2：批量替换（推荐）
```
1. Word文档中按 Ctrl+H 打开查找替换
2. 查找：$$[内容]$$
3. 替换：留空
4. 点击「全部替换」删除LaTeX标记
```

### 步骤3：插入Word公式
```
1. 光标定位到公式位置
2. 按 Alt + = 打开公式编辑器
3. 从公式文件复制数学表达式
4. 粘贴到公式编辑器
5. 调整格式
```

## 🚨 常见错误速查

| 错误现象 | 原因 | 解决方法 |
|---------|------|----------|
| 公式显示为文本 | 未进入公式编辑器 | 先按Alt+=再粘贴 |
| 上标变普通文本 | 格式未识别 | 手动调整上标位置 |
| 向量未加粗 | 缺少加粗标记 | 选中后Ctrl+B |
| 编号位置错误 | 对齐问题 | 右对齐编号 |
| 符号显示为□ | 字体不支持 | 改用Cambria Math |

## 📞 快速故障排除

### 问题：公式太大
**解决**：选中公式 → 右键 → 字体 → 12pt

### 问题：公式太小
**解决**：选中公式 → 右键 → 字体 → 14pt或16pt

### 问题：上标下标显示错误
**解决**：手动调整 → 选中 → 格式 → 字体 → 上标/下标

### 问题：特殊符号无法输入
**解决**：插入 → 符号 → 选择符号
