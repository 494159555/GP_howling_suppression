第3章 实验设计

本章全面介绍实验的实施方案，涵盖啸叫仿真数据集的构建、特征提取步骤、四个U-Net模型架构、三种传统算法实现、损失函数设计、数据增强手段及评价指标体系。

3.1 数据集构建

3.1.1 基于RIR的声反馈模拟方法

鉴于公开的啸叫数据集数量有限，本文采用房间脉冲响应（RIR）模拟技术生成训练样本。RIR刻画了声波从声源到接收点在室内的传播特性，涵盖了直达声和多次反射声。研究采用图像法生成RIR来模拟声反馈回路，通过调整房间几何尺寸、混响时间、麦克风与扬声器位置等变量，构建具备多样化声学特性的脉冲响应。

3.1.2 仿真参数配置

为保障数据集的多样性，仿真过程中对核心参数实施随机化配置。RIR相关参数包括随机生成的房间长宽高、麦克风及扬声器坐标，混响时间（RT60）在0.1至0.5秒区间随机抽取，其中较小值对应吸声较强的环境，较大值代表混响显著的场景。系统延迟Δt在0.02至0.2秒区间随机生成，以模拟信号处理与传输的时延；增益G在5dB至10dB区间随机选取，保证多数情形下能够触发啸叫。同时，引入硬限幅和Sigmoid非线性变换，用于模拟放大器在饱和状态下的削波和谐波失真现象。

3.1.3 仿真数据生成步骤

具体生成过程如下：首先选取纯净语音作为初始麦克风输入y(t)，依据帧移大小逐帧迭代处理。对每帧信号执行以下操作：（1）施加随机增益G进行信号放大；（2）引入非线性失真处理，获得扬声器输出信号x(t)；（3）将RIR与播放信号卷积，计算反馈信号d(t)；（4）将经过延迟的反馈信号叠加至下一帧麦克风输入。循环处理直至所有帧完成，最终输出带有啸叫成分的混合信号。

3.1.4 数据集划分策略

数据集采用三分法划分为训练集、验证集和测试集，所有音频统一采用16kHz采样率。为确保测试结果的客观性，测试集所用的RIR参数与训练验证集完全隔离，即测试集包含的声反馈路径在训练阶段未曾出现过。这种划分方式旨在验证模型对未知声学环境的适应能力。

3.2 特征提取

3.2.1 STFT参数配置

通过短时傅里叶变换（STFT）将时域音频信号映射至时频域。FFT点数设为512（等效32毫秒帧长），帧移设为128点（等效8毫秒帧移），帧间重叠率达75%以维持时间维度的连续性。选用汉明窗函数抑制频谱泄漏效应，对输出功率谱开平方获得幅度谱。

3.2.2 对数幅度谱计算

利用STFT得到时频表示Y(m,k)，其中m代表帧序号，k代表频率序号。当FFT点数为512时，频率维度包含257个频点（覆盖0Hz至奈奎斯特频率8000Hz）。对功率谱开平方得到幅度谱|Y(m,k)|。选择幅度谱而非复数谱作为网络输入，因为模型仅需在幅度域预测掩膜，相位分量可直接取自原始信号，从而简化特征表达。

3.2.3 频谱归一化

将幅度谱经对数变换和线性映射归一化至[0, 1]区间。首先计算以10为底的对数Y_log(m,k) = log_10(|Y(m,k)| + ε)，其中ε = 10^(-8)用于防止数值溢出，对数域数值大致分布于[-8, 2]范围。继而通过线性变换Y_norm(m,k) = (Y_log(m,k) - norm_min)/(norm_max - norm_min)将值归一化至[0, 1]，其中norm_min = -11.5，norm_max = 2.5。采用固定的归一化边界值以保证各样本间的可比性。对纯净语音执行相同处理流程作为网络训练的目标。

3.2.4 输入输出维度

神经网络的输入为带啸叫音频的归一化对数幅度谱，张量形状为[B, 1, 256, T]，其中B表示批次大小，256为频率维数（从原257个频点裁减至256），T为时间帧数。输出目标是纯净音频的归一化对数幅度谱，形状与输入一致。频率维度的裁减通过切片方式舍弃最后一个频点（即奈奎斯特频率点），使维度成为2的幂次以适配卷积运算，该操作对信号质量的影响微乎其微。

3.3 模型架构设计

3.3.1 基础U-Net模型（AudioUNet3）

AudioUNet3作为最小可实现的基线模型，采用三层编码器-解码器架构。编码器含三个下采样模块，通道数依次递增为1、16、32、64，每个模块包含步长为(2,1)的3×3卷积层、批量归一化层和LeakyReLU（负斜率0.2）激活函数，频率维数从256缩减至32。解码器含三个上采样模块，通道数递减为64、32、16、1，利用转置卷积恢复频率分辨率，并通过跳跃连接将编码器各层特征与解码器相应层拼接。输出层采用转置卷积配合Sigmoid激活函数产生[0, 1]区间的掩膜，最终输出计算为Ŷ = Y_norm × Mask。该模型包含约120万参数。

3.3.2 标准U-Net模型（AudioUNet5）

AudioUNet5为五层U-Net架构，设定为本文的默认模型。编码器由五个下采样模块构成，通道数依次递增至1、16、32、64、128、256，频率维度压缩至1/32。解码器由五个上采样模块构成，通过转置卷积重建频率分辨率，并借助跳跃连接与编码器对应层进行特征融合。相较于AudioUNet3，该模型增加了两层编解码结构，参数量约450万，更大的感受野和更丰富的多尺度特征提取能力使其能够学习更抽象、更全局的频谱表示。

3.3.3 注意力U-Net模型（AudioUNet5Attention）

AudioUNet5Attention在AudioUNet5架构上为所有跳跃连接引入了注意力门机制。编码器特征在传递至解码器之前需经过注意力门的筛选，注意力门接收编码器特征x和解码器上层的门控信号g，自适应地生成[0, 1]区间的注意力权重系数，从而实现特征的选择性传递。在四个跳跃连接位置分别设置了不同通道规格的注意力门：att4（128/128/64）、att3（64/64/32）、att2（32/32/16）、att1（16/16/8）。注意力门通过1×1卷积变换、ReLU和Sigmoid函数输出注意力系数，当尺寸不一致时采用双线性插值进行对齐。该机制使网络能够自动聚焦于啸叫相关区域，提升掩膜估计的准确性。

3.3.4 综合优化U-Net模型（AudioUNet5Optimized）

AudioUNet5Optimized为性能最优版本，在AudioUNet5Attention基础上融合了残差连接和空洞卷积技术。每个编码器层由标准下采样模块和残差模块构成，残差模块包含两个3×3卷积层和批量归一化，通过残差连接有效缓解深层网络的梯度衰减问题。瓶颈层设计了空洞卷积模块，采用空洞率分别为2、4、8的三个并行空洞卷积分支，各分支输出约85个通道，拼接后经1×1卷积映射回256通道。空洞卷积以不同的感受野捕获多尺度频谱上下文，在不增加参数开销的情况下获取全局感知能力。三种改进协同作用：残差连接提升训练效率，空洞卷积扩展感受野，注意力门实现精准聚焦。

3.4 传统算法实现

为进行全面的对比评估，本文实现了三种传统啸叫抑制算法作为基线方法。

3.4.1 移频法（FrequencyShiftMethod）

移频法的基本思路是在频域对信号施加微小的频率偏移，以破坏啸叫产生的正反馈相位条件。该方法在STFT域实现，频率偏移量Δf默认设定为20Hz，频率分辨率Δf_res = 31.25Hz，由此计算出频点偏移量shift_bins = Δf / Δf_res。对于每个输出频点，计算其在原始频谱中的目标位置，采用线性插值方式获取该位置的频谱值。同时预先计算相位调整因子exp(j · 2π · Δf · n · H / f_s)以维持时频域的一致性。该方法的优点是实现简便、计算开销小，但频率偏移操作会改变原始信号的频率结构，造成音质损失。

3.4.2 增益抑制法（GainSuppressionMethod）

增益抑制法通过识别啸叫频段并施加自适应的增益衰减来抑制啸叫。啸叫检测在1000Hz至8000Hz频带内进行，基于信噪比阈值进行判别：利用指数移动平均（系数α = 0.95）维持背景能量估计，计算当前帧频谱能量与背景估计的比值作为信噪比，当信噪比超过阈值（默认-30dB）且为局部峰值（与相邻±2个频点比较）时，将该频点判定为啸叫点。增益控制的最大衰减量默认为-20dB，采用平滑过渡策略，攻击时间设定为0.01秒、释放时间为0.1秒，保证快速的啸叫抑制和缓慢的增益恢复。该方法的优势是处理策略清晰直观，但其效果在很大程度上依赖于啸叫检测算法的准确性。

3.4.3 自适应反馈消除法（AdaptiveFeedbackMethod）

自适应反馈消除法利用自适应滤波器在线估计声反馈路径，并从输入信号中减去估计的反馈分量。该算法采用NLMS（归一化最小均方）实现，滤波器长度设为64个抽头，步长取0.01以控制收敛速度，泄漏因子设为0.9999防止系数无界增长，开启归一化处理以提高不同信号功率下的稳定性，最大增益限制为20dB以防止数值溢出。处理流程包括：计算当前帧的平均能量作为输入，将输入缓冲区与滤波器系数进行内积运算得到预测的反馈信号，计算误差信号，利用误差信号和输入缓冲区更新滤波器系数。滤波器系数经泄漏因子衰减后进行限幅处理。该方法的理论优势在于直接对反馈路径进行建模，但由于目标信号与反馈信号之间的高度相关性，实际效果受到一定限制。

3.5 损失函数

3.5.1 基础损失函数

L1损失（又称平均绝对误差）计算预测频谱与目标频谱之间逐元素差绝对值的平均：L_L1 = (1/N)∑|ŷ_i - y_i|。L1损失对异常值具有鲁棒性，能够产生稀疏梯度，适用于频谱级别的回归任务。MSE损失计算逐元素差平方的平均：L_MSE = (1/N)∑(ŷ_i - y_i)^2。MSE对较大误差施加更强的惩罚，促使模型更加关注难以拟合的样本，但在训练后期可能导致输出过于平滑。

3.5.2 频谱损失

频谱损失在对数域计算预测频谱与目标频谱的L1距离：L_spectral = (1/N)∑|log_10(ŷ_i + ε) - log_10(y_i + ε)|。与线性域的误差度量不同，对数域使得不同能量级别上的误差贡献更加均衡，网络在训练过程中对各能量级别的频点给予相对均衡的关注，从而提升整体频谱重建质量。

3.5.3 多任务组合损失

多任务组合损失将多种损失函数进行加权整合：L_multitask = w_spectral·L_spectral + w_L1·L_L1 + w_MSE·L_MSE + w_consistency·L_consistency。默认权重配置为w_spectral = 0.5、w_L1 = 0.3、w_MSE = 0.2、w_consistency = 0，其中频谱损失权重最高，强调对数域的重建精度；L1损失提供稳定的梯度信号；MSE损失关注大误差的修正；频谱一致性损失作为可选项（默认不启用），通过惩罚频谱在频率和时间维度上的不连续性来减少伪影：L_consistency = λ_f·(1/N)∑|∇_f Ŷ| + λ_t·(1/N)∑|∇_t Ŷ|，其中∇_f和∇_t分别表示频率维度和时间维度的差分，λ_f和λ_t默认均取0.1。多任务组合损失是本文默认采用的损失函数，综合了多种误差度量的优势。

3.6 数据增强

3.6.1 音频域增强

音频域增强在STFT之前对时域波形施加变换操作。噪声注入以50%的概率叠加零均值高斯白噪声，噪声强度从预设等级列表（0.001、0.01、0.02、0.05）中随机抽取，提升模型对噪声干扰的鲁棒性。音量调整以一定概率对波形振幅乘以随机因子，因子从预设系数列表（0.7、0.8、0.9、1.0、1.1、1.2、1.3）中随机选取，增强后通过限幅操作将幅度限制在[-1.0, 1.0]范围内，提高对不同信号强度的适应能力。时间偏移以一定概率沿时间轴进行随机平移，最大偏移比例为信号长度的10%，增强对时间扰动的不变性。

3.6.2 频谱域增强（SpecAugment）

SpecAugment在STFT之后对归一化的频谱图施加变换。频率掩码以一定概率沿频率轴施加条带状遮罩，遮罩宽度在0至最大宽度（默认20个频点）之间随机选取，将指定频率范围内的频谱值置零，默认每个样本施加2个频率掩码。时间掩码以一定概率沿时间轴施加条带状遮罩，遮罩宽度在0至最大宽度（默认20个时间帧）之间随机选取，默认每个样本施加2个时间掩码。频谱抖动以一定概率添加零均值、标准差为0.01的高斯噪声，增强后通过限幅操作将值限制在[0, 1]范围内，提高模型对输入扰动的稳定性。

3.6.3 Mixup混合增强

Mixup通过在样本对之间进行线性插值来构造新的训练样本。给定两个训练样本(x_1, y_1)和(x_2, y_2)，生成新的样本对：x̃ = λx_1 + (1-λ)x_2, ȳ = λy_1 + (1-λ)y_2，其中λ服从Beta(α, α)分布，α为Mixup参数（默认0.4），为保证混合样本仍以其中一个原始样本为主导，将λ的取值限制为max(λ, 1-λ)。Mixup增强了训练数据的多样性，促使模型学习更平滑的决策边界，有助于缓解过拟合问题。

3.7 评价指标

3.7.1 尺度不变信噪比（SI-SDR）

尺度不变信噪比（SI-SDR）是音频增强领域普遍采用的客观评价指标，用于衡量增强后信号与干净参考信号之间的失真程度。SI-SDR具有尺度不变性，对增强信号的全局缩放不敏感，因而能够更公平地评估信号重建质量。其计算过程为：对增强信号进行最优缩放投影s_target = (⟨ŝ, s⟩/||s||²) · s，计算失真分量e_noise = ŝ - s_target，SI-SDR = 10log_10(||s_target||²/||e_noise||²)，其中s表示干净参考信号，ŝ表示增强后的输出信号。SI-SDR数值越高，说明失真越小，信号重建质量越好。

3.7.2 语音质量感知评估（PESQ）

语音质量感知评估（PESQ）是国际电信联盟推荐的客观语音质量评估标准（P.862），用于预测听众对处理后语音的主观质量评价。PESQ通过对比原始纯净语音和处理后语音的感知特征（涵盖频谱包络、时间包络、响度和失真等方面），输出-0.5至4.5区间的评分，评分越高表示语音质量越好。通常情况下，PESQ评分超过3.0被视为具有"良好"质量，超过3.5则被认为具有"优秀"质量。计算过程包括信号预处理（电平对齐、IRF滤波）、时间对齐、频率变换和感知加权，模拟人类听觉系统的处理机制，本文采用16kHz采样率下的宽带PESQ模式。

3.7.3 短时客观可懂度（STOI）

短时客观可懂度（STOI）是语音可懂度评估指标，用于衡量处理后语音与纯净语音在短时间尺度内时间包络的相关性。STOI数值介于0至1之间，数值越接近1说明处理后的语音与原始语音在时间包络特征上越接近，语音可懂度和清晰度越高。计算过程为：对纯净语音和处理后语音进行短时帧划分，提取各帧的时间包络特征，计算两者在各帧上的相关系数，最后对所有帧的相关系数求平均。STOI用于评估啸叫抑制处理后语音的可懂度保持情况，理想的啸叫抑制方法应当在有效抑制啸叫的同时尽可能保持语音的可懂度。

此外，在模型对比实验中，本文还记录了各模型的参数量和推理时间作为计算效率的参考指标。参数量统计模型中所有可训练参数总数，推理时间测量模型处理单条音频样本所需的平均时间。综合上述三项核心评价指标（SI-SDR、PESQ、STOI）以及计算效率参考，能够从信号重建质量、主观听觉质量、语音可懂度保持和实际部署可行性等多角度全面评估各方法的综合性能。
