## 在Word中插入公式的方法

### 方法一：使用快捷键（推荐）

1. 将光标定位到需要插入公式的位置
2. 按快捷键 `Alt + =` 打开公式编辑器
3. 复制公式中的数学表达式
4. 粘贴到公式编辑器中
5. Word会自动转换为可编辑公式

### 方法二：使用菜单

1. 将光标定位到需要插入公式的位置
2. 点击菜单栏「插入」→「公式」
3. 在公式编辑器中粘贴数学表达式
4. 调整格式和大小

### 方法三：使用LaTeX语法（需要MathType或公式编辑器插件）

1. 安装MathType或Word公式编辑器插件
2. 使用LaTeX语法输入公式
3. 插件会自动转换为Word公式格式

## 批量替换方案

### 方案A：手动逐个替换（最可靠）

1. 打开 `02_chapter2_word_formulas.md`
2. 打开Word中的原论文文档
3. 按章节顺序，逐个替换公式
4. 使用 `Ctrl+F` 搜索公式编号（如 `(2.1)`）
5. 删除原LaTeX公式块 `$$...$$`
6. 在相同位置插入Word公式
7. 重复步骤4-6直到全部完成

**优点**：准确率高，不易出错
**缺点**：耗时较长（约30-60分钟）

### 方案B：查找替换法（半自动）

1. 打开Word文档
2. 使用 `Ctrl+H` 打开查找替换对话框
3. 在「查找内容」中输入LaTeX公式（包含 `$$` 标记）
4. 在「替换为」中留空
5. 点击「全部替换」删除所有LaTeX公式
6. 手动在相应位置插入Word公式

**优点**：快速清理LaTeX标记
**缺点**：需要手动定位每个公式位置

### 方案C：VBA宏批量处理（进阶）

```vba
Sub ReplaceLatexFormulas()
    Dim rng As Range
    Set rng = ActiveDocument.Content
    
    ' 替换特定公式
    With rng.Find
        .Text = "$$x(t) = y(t - \Delta t) \times G \tag{2.1}$$"
        .Replacement.Text = ""
        .Execute Replace:=wdReplaceAll
    End With
    
    ' 继续替换其他公式...
    
    MsgBox "LaTeX公式已清理，请手动插入Word公式"
End Sub
```

**优点**：批量清理LaTeX标记
**缺点**：仍需手动插入Word公式

## 常见问题及解决方案

### Q1: 粘贴后公式格式错乱

**解决方案**：
- 先删除原LaTeX公式块
- 使用 `Alt + =` 打开公式编辑器
- 在公式编辑器中粘贴
- 检查并调整上标下标

### Q2: 某些特殊符号无法显示

**解决方案**：
- 确保字体支持Unicode（推荐Cambria Math）
- 使用插入符号功能手动添加
- 或者使用MathType等插件

### Q3: 公式编号无法右对齐

**解决方案**：
- 使用制表符设置右对齐
- 或使用表格（3列：左边距、公式、编号）
- 公式列居中，编号列右对齐

### Q4: 向量加粗不显示

**解决方案**：
- 选中变量
- 使用 `Ctrl+B` 加粗
- 或在公式编辑器中使用粗体按钮

### Q5: 公式太大或太小

**解决方案**：
- 选中公式
- 右键→段落→字体大小
- 设置为12pt与正文一致
- 上标下标设为8pt
