# 第4章 实验组织

本章将详细阐述实验的组织方案与具体实施流程。首先介绍实验所需的硬件与软件环境配置，然后依次说明六组实验的具体方案设计，包括模型训练与对比实验、统一评估实验、消融实验、损失函数对比实验、训练策略对比实验和数据增强对比实验，最后给出可视化方案。

## 4.1 实验环境

### 4.1.1 硬件环境

本实验的所有模型训练与推理均在以下硬件平台上完成：

- **GPU**：NVIDIA GeForce RTX 4090（24GB显存），支持CUDA计算能力8.9
- **CPU**：Intel Core i9-13900K（24核/32线程）
- **内存**：64GB DDR5
- **存储**：1TB NVMe SSD，用于存放数据集与模型检查点

在训练过程中，U-Net基础模型（v1、v2）的单卡显存占用约为4—6GB，引入注意力机制的v3模型约为8—10GB，综合优化模型（v6）约为10—12GB，GAN变体（v10）由于包含生成器与判别器，显存占用约为14—16GB。所有模型均可在单卡上完成训练，无需分布式训练。

### 4.1.2 软件环境

实验所使用的软件环境如下：

- **操作系统**：Ubuntu 22.04 LTS
- **Python版本**：3.10
- **深度学习框架**：PyTorch 2.1.0 + torchvision 0.16.0
- **CUDA版本**：CUDA 12.1，cuDNN 8.9
- **音频处理库**：librosa 0.10.1、scipy 1.11.4、soundfile 0.12.1
- **评价工具**：pesq 0.0.4（PESQ指标）、pystoi 0.3.3（STOI指标）
- **可视化工具**：matplotlib 3.8.2、seaborn 0.13.0
- **实验管理**：PyYAML 6.0.1（配置管理）、tensorboard 2.15.0（训练日志）

所有实验配置均通过YAML文件统一管理，确保实验的可复现性。

## 4.2 实验方案

### 4.2.1 实验1：模型训练与对比

本实验旨在统一训练所有深度学习模型变体，并在相同条件下对比各模型的性能差异。

**实验模型：**

本实验涉及五类U-Net模型变体和三种传统基线方法，具体如下：

1. **U-Net V1（基础版）**：标准U-Net结构，包含编码器（下采样）与解码器（上采样）的对称4层结构，每层使用双卷积块（Conv2d → BatchNorm → ReLU × 2），跳跃连接采用拼接方式。输入为STFT复数矩阵的实部与虚部双通道，输出为增强后的复数矩阵。

2. **U-Net V2（残差改进版）**：在V1基础上引入残差连接，每个卷积块内部增加跳跃连接，缓解深层网络的梯度退化问题。编码器通道数为[64, 128, 256, 512]，解码器对应对称。

3. **U-Net V3（注意力增强版）**：在V2基础上引入注意力门机制，在跳跃连接处添加空间注意力模块，使模型能够自适应地聚焦于啸叫频率区域，抑制无关背景信息。

4. **U-Net V6（综合优化版）**：融合注意力机制、残差连接和空洞卷积的综合优化模型。空洞卷积的膨胀率设置为[1, 2, 4]，在不增加参数量的前提下扩大感受野，捕获更广的频率上下文信息。

5. **U-Net V10（GAN变体）**：以U-Net V6作为生成器，引入PatchGAN判别器组成的生成对抗网络。生成器目标为生成接近干净语音的频谱，判别器目标为区分生成频谱与真实干净频谱，通过对抗训练提升增强质量。

6. **传统方法——增益抑制法**：通过检测频谱能量峰值，对超过阈值的频段进行增益衰减来抑制啸叫。设置峰值检测阈值为基础能量的6dB。

7. **传统方法——移频法**：通过将信号频谱整体偏移5Hz来破坏啸叫的正反馈相位条件，实现啸叫抑制。

8. **传统方法——自适应反馈抑制法**：基于NLMS自适应滤波器的反馈路径估计方法，滤波器阶数设为512，步长因子设为0.01。

**训练流程：**

所有深度学习模型遵循统一的训练流程：

1. 加载预生成的训练数据集与验证数据集，数据以STFT复数矩阵形式存储。
2. 根据各模型YAML配置文件初始化网络结构与优化器。
3. 采用混合精度训练（AMP）加速训练过程，使用GradScaler处理梯度缩放。
4. 每个epoch结束后在验证集上计算SI-SDR和PESQ指标，保存最优模型检查点。
5. 启用早停机制，若验证损失连续15个epoch未下降，则提前终止训练。
6. 记录完整的训练日志（损失曲线、指标变化、学习率变化等），保存至TensorBoard。

### 4.2.2 实验2：统一评估

本实验对所有深度学习模型及三种传统方法进行统一评估，以公平比较各方法的性能。

**评估流程：**

1. 对测试集中每条音频，分别使用八种方法（五个深度学习模型 + 三个传统方法）进行处理。
2. 对处理后的音频与对应的干净参考音频，计算以下评价指标：
   - **SI-SDR**（尺度不变信噪比）：衡量信号的失真程度，值越高表示增强效果越好。
   - **PESQ**（语音质量感知评估）：衡量主观听觉质量，评分范围为0.5—4.5，值越高表示语音质量越好。
   - **STOI**（短时客观可懂度）：衡量语音可懂度，值范围为0—1，值越高表示语音越清晰。
3. 汇总所有测试样本的指标，计算平均值和标准差，生成对比表格与可视化图表。
4. 同时记录各方法的推理时间，评估其实时处理能力。

### 4.2.3 实验3：消融实验

本实验针对综合优化模型（U-Net V6）进行组件消融研究，分别验证注意力机制、残差连接和空洞卷积三个关键组件的贡献。

**消融方案：**

以完整的U-Net V6作为基准（Full），依次移除各个组件，形成以下消融组合：

1. **Full（完整模型）**：包含注意力机制 + 残差连接 + 空洞卷积。
2. **w/o Attention（移除注意力）**：移除注意力门机制，跳跃连接退化为标准拼接方式。
3. **w/o Residual（移除残差连接）**：将残差卷积块替换为标准双卷积块。
4. **w/o Dilated（移除空洞卷积）**：将空洞卷积替换为标准卷积，膨胀率统一设为1。
5. **Baseline（全移除）**：同时移除三个组件，退化为基础U-Net结构。

每种消融配置均在相同的训练参数下重新训练至收敛，然后在测试集上评估SI-SDR、PESQ和STOI三项指标。通过对比各配置与完整模型的指标差异，量化各组件的独立贡献度。

### 4.2.4 实验4：损失函数对比

本实验研究不同损失函数对U-Net V6模型训练效果的影响。

**对比的损失函数：**

1. **MSE Loss（均方误差损失）**：预测频谱与目标频谱之间的均方误差，是最基础的回归损失函数。

$$L_{MSE} = \frac{1}{N}\sum_{i=1}^{N}\|S_{pred}^{(i)} - S_{clean}^{(i)}\|_2^2$$

2. **L1 Loss（平均绝对误差损失）**：预测频谱与目标频谱之间的L1距离，对异常值不如MSE敏感。

$$L_{L1} = \frac{1}{N}\sum_{i=1}^{N}\|S_{pred}^{(i)} - S_{clean}^{(i)}\|_1$$

3. **SI-SDR Loss（尺度不变信噪比损失）**：直接以SI-SDR指标的负值作为损失函数，优化信号级别的失真。

$$L_{SI\text{-}SDR} = -10\log_{10}\frac{\|s_{target}\|_2^2}{\|s_{noise}\|_2^2}$$

4. **Multi-Resolution STFT Loss（多分辨率STFT损失）**：在多个STFT分辨率下计算频谱L1损失，综合不同时频分辨率的误差信息。本实验使用三个分辨率：帧长分别为[512, 256, 128]。

$$L_{MR\text{-}STFT} = \sum_{k=1}^{K}\left(\|S_{pred}^{(k)} - S_{clean}^{(k)}\|_1 + \|\log|S_{pred}^{(k)}| - \log|S_{clean}^{(k)}|\|_1\right)$$

5. **Composite Loss（复合损失函数）**：将多分辨率STFT损失与SI-SDR损失按权重组合，兼顾频谱级别的重构精度和信号级别的失真度量。

$$L_{Composite} = \alpha \cdot L_{MR\text{-}STFT} + \beta \cdot L_{SI\text{-}SDR}$$

其中 $\alpha = 1.0$，$\beta = 0.5$。

**实验流程：**

固定模型架构为U-Net V6，其他超参数保持不变，仅替换损失函数进行训练。每种损失函数独立训练至收敛后，在测试集上评估三项指标。

### 4.2.5 实验5：训练策略对比

本实验对比不同学习率调度策略对模型训练效果的影响。

**对比的学习率调度策略：**

1. **CosineAnnealingLR**：余弦退火调度，学习率按余弦函数从初始值缓慢衰减至最小值（1×10⁻⁶），周期与训练总轮数一致，适合平稳收敛。

2. **ReduceLROnPlateau**：自适应衰减调度，监控验证损失指标，若连续5个epoch验证损失未下降，则将学习率乘以衰减因子0.5，最小学习率为1×10⁻⁶。

3. **CyclicLR**：循环学习率调度，学习率在1×10⁻⁵到1×10⁻³之间三角循环变化，步长设置为训练轮数的两倍，有助于逃离局部最优。

4. **OneCycleLR**：单周期调度，学习率先从1×10⁻⁵线性增长至峰值1×10⁻³（占训练前30%），再退火至1×10⁻⁶，兼具预热与衰减效果。

5. **Warmup + CosineDecay**：线性预热调度，前5个epoch学习率从1×10⁻⁶线性增长至1×10⁻³，之后按余弦函数衰减至1×10⁻⁶。

**实验流程：**

固定模型架构为U-Net V6，损失函数使用复合损失函数（Composite Loss），仅替换学习率调度策略，其他超参数保持不变。记录各策略下的训练收敛速度（达到最优验证指标所需的epoch数）和最终测试性能。

### 4.2.6 实验6：数据增强对比

本实验研究不同数据增强策略对模型泛化能力的影响。

**对比的数据增强策略：**

1. **无增强（Baseline）**：训练过程中不使用任何数据增强，仅使用原始的STFT特征。

2. **频率掩蔽（FreqMask）**：参照SpecAugment方法，在频谱图上随机遮挡连续的频率带，掩蔽宽度最大为20个频率点，模拟部分频率信息丢失的情况。

3. **时间掩蔽（TimeMask）**：在频谱图上随机遮挡连续的时间帧，掩蔽宽度最大为20帧，模拟短时信号中断的情况。

4. **频率 + 时间联合掩蔽（JointMask）**：同时应用频率掩蔽和时间掩蔽，增加数据多样性。

5. **综合增强（Full Augmentation）**：在联合掩蔽的基础上，增加以下增强操作：
   - 随机增益缩放：对频谱幅度乘以[0.8, 1.2]范围内的随机系数，模拟音量变化。
   - 随机噪声注入：添加信噪比在[20, 40]dB范围内的白噪声，提升模型对噪声的鲁棒性。
   - 频谱混合：以[0.1, 0.5]的混合比例对两个样本的频谱进行线性插值。

**实验流程：**

固定模型架构为U-Net V6，损失函数和学习率调度策略保持不变。对每种增强策略，在训练集上应用相应的数据增强后训练至收敛，然后在未增强的测试集上评估三项指标。

## 4.3 可视化方案

为直观展示实验结果，本实验设计以下可视化方案：

1. **频谱对比图**：对每个测试样本，以三行子图分别展示干净语音、带啸叫语音和增强后语音的时频频谱图，便于直观对比啸叫频率区域的抑制效果。

2. **训练曲线**：绘制各模型训练过程中的损失曲线、SI-SDR曲线和PESQ曲线，横轴为训练轮数，纵轴为对应指标值，用于分析收敛速度和稳定性。

3. **模型性能雷达图**：以雷达图形式展示各模型在SI-SDR、PESQ、STOI、推理时间和参数量等多个维度上的综合性能，便于整体比较。

4. **消融实验热力图**：以热力图形式展示消融实验中各组件在不同指标上的贡献度，用颜色深浅直观表示各组件的重要性。

5. **损失函数对比柱状图**：以分组柱状图展示不同损失函数在各项指标上的表现，配合误差棒显示标准差。

6. **学习率调度对比曲线**：绘制各学习率调度策略的学习率变化曲线和对应的验证损失变化曲线。
