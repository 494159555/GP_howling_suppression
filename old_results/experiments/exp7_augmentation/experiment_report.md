## 4. 结果分析

### 4.1 主要发现

1. **增强效果微小**: 5种增强策略在所有指标上的表现几乎完全一致，差异极小（SNR差异仅0.09dB）。
   - 最佳SNR: FullAugmentation (46.18dB)
   - 最差SNR: JointMask (46.09dB)
   - 差异范围: 仅0.09dB

2. **STOI完全一致**: 所有策略的STOI得分均为1.0000，说明语音可懂度均达到完美水平。

3. **MOS评分相同**: 所有策略的估计MOS得分均为4.60。

4. **综合增强略有优势**: FullAugmentation在SNR指标上表现最好（46.18dB），比基线高0.06dB，但优势可忽略不计。

### 4.2 可能原因分析

1. **数据特性**: 啸叫抑制任务的训练数据可能已经足够丰富，增强策略的边际收益极小。

2. **模型容量**: AudioUNet5Optimized的3.1M参数量可能已经足够学习到有效的特征表示，不需要通过增强来提升泛化能力。

3. **频谱域特性**: 数据已经经过对数变换和归一化处理到[0,1]范围，掩蔽操作的效果可能被归一化所削弱。

4. **训练收敛充分**: 所有策略在50个epoch后都收敛到几乎相同的损失值（~0.00994），说明模型已达到该架构的性能上界。

### 4.3 实验结论

在当前实验设置下（AudioUNet5Optimized + Composite Loss + Warmup+CosineDecay），数据增强策略对啸叫抑制性能的影响**不显著**。所有增强策略均达到了近乎相同的性能水平。这表明：

- 模型本身已具备良好的特征提取和泛化能力
- 增强策略在该任务上的收益有限
- 建议在实际部署中采用基线方案（无增强），以获得最快的训练速度
