# 深度学习实验项目 - Cline 执行规则
> 工作区项目规则，仅对当前实验项目生效，所有AI操作必须严格遵循以下规范

## 一、环境配置强制规则
1. **虚拟环境优先级**
   所有Python代码、实验脚本、命令执行，**必须优先激活专属虚拟环境**：
   ```bash
   conda activate GraduationProject
   ```
   禁止使用全局Python环境、其他虚拟环境执行任何实验相关操作。

2. **环境校验**
   执行实验前，自动校验虚拟环境是否激活，未激活则终止操作并提示激活。

---

## 二、GPU资源检查与使用核心规则
### 1. GPU检查命令（固定执行）
执行实验前**必须自动运行**GPU状态检查命令：
```bash
nvidia-smi --query-gpu=index,memory.used,memory.free,memory.total --format=csv,noheader
```

### 2. GPU分配标准（动态决策）
根据检查结果**自动选择GPU数量**，严格遵循以下逻辑：
- **空闲充足**：单张GPU空闲显存 ≥ 8GB 或 空闲比例 ≥ 70% → 使用 **2~3张GPU** 加速实验
- **空闲不足**：单张GPU空闲显存 < 8GB 或 空闲比例 < 70% → 仅使用 **1张GPU** 运行实验
- **无空闲GPU**：终止实验执行，提示等待GPU资源释放

### 3. GPU调用规范
- 必须通过 `CUDA_VISIBLE_DEVICES` 指定GPU编号（如 `CUDA_VISIBLE_DEVICES=0,1`）
- 禁止无指定调用全部GPU，禁止占用非空闲GPU

---

## 三、实验执行规范
1. 所有实验脚本必须在**激活虚拟环境+确认GPU资源**后执行
2. 实验运行时必须保留日志输出，禁止屏蔽报错信息
3. 训练/推理脚本优先使用命令行模式执行，禁止手动修改核心参数
4. 实验中断后，优先支持断点续跑，禁止从头重新训练

---

## 四、代码辅助规范
1. 深度学习代码遵循PyTorch最佳实践，优化显存占用、加速训练
2. 代码注释清晰，标注实验参数、GPU使用配置
3. 辅助编写脚本时，自动适配多GPU/单GPU运行逻辑

---

## 五、深度学习实验额外优化建议（AI必须遵守）
1. **显存优化**
   自动建议混合精度训练、梯度累积、减小batch size等显存优化方案，避免OOM报错
2. **日志管理**
   辅助生成实验日志保存脚本，自动记录GPU使用率、训练loss、实验结果
3. **监控建议**
   推荐实时监控工具：`watch -n 1 nvidia-smi`，持续观测GPU状态
4. **断点续跑**
   所有训练脚本必须支持断点续跑，自动保存模型权重、优化器状态
5. **错误排查**
   实验报错时，优先排查：虚拟环境未激活、GPU被占用、显存不足、CUDA版本不匹配
6. **效率提升**
   多GPU运行时，自动推荐 `DataParallel` 或 `DistributedDataParallel` 多卡训练方案

---

## 六、禁止行为
1. 禁止不检查GPU直接运行实验
2. 禁止使用非指定虚拟环境
3. 禁止随意占用全部GPU资源
4. 禁止屏蔽实验日志和报错信息

---
